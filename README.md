# Ricetta - Tuscan Recipe & Cocktail Book

Editorial recipe directory and cocktail handbook built with Next.js 14 and TypeScript strict mode, featuring warm Mediterranean typography.

- **Live URL**: https://ricetta.vercel.app
- **Framework**: Next.js 14.2.35 (TypeScript 5.4, Node 22 LTS)
- **Data Source**: TheMealDB & TheCocktailDB Public REST APIs
- **Design Concept**: Tuscan Osteria Editorial

---

## Features

- **Strict TypeScript Architecture**: Type-safe recipe and ingredient models across all pages and components.
- **Dual Catalog**: Browse Italian dishes, regional pasta, and international cocktails with step-by-step instructions.
- **Interactive Measurement Guide**: Dynamic ingredient checklist and embedded instructional video modal.
- **Zero API Key Leak**: Fully relies on public educational endpoints without requiring sensitive environment secrets.
- **Responsive Layout**: Designed for mobile cooking sessions as well as desktop browsing.

---

## Tech Stack

- **Framework**: Next.js 14 (Pages Router)
- **Language**: TypeScript (Strict Mode)
- **Styling**: Tailwind CSS
- **Icons & Typography**: Fraunces, Plus Jakarta Sans, Heroicons
- **Deployment**: Vercel

---

## Getting Started

```bash
git clone https://github.com/rioxiu/ricetta.git
cd ricetta
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.
